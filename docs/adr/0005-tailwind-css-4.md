# 0005. Tailwind CSS 4 with design tokens

Status: Accepted
Date: 2026-09-19

## Context

The site needs consistent styling that scales across hundreds of tool pages.

## Decision

Use Tailwind CSS 4 with design tokens. The design system is built in Mission 6.

## Consequences

Styling goes through shared tokens instead of one-off values.
