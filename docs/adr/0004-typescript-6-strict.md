# 0004. TypeScript 6 strict

Status: Accepted
Date: 2026-09-19

## Context

astro check uses the classic TypeScript API that TypeScript 7 replaced.

## Decision

Use TypeScript 6 in strict mode.

## Consequences

The project stays on TypeScript 6 until astro check works with TypeScript 7.

## Revisit when

astro check supports TypeScript 7.
