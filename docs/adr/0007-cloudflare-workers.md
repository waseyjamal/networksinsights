# 0007. Cloudflare Workers with static assets for hosting

Status: Accepted
Date: 2026-09-19

## Context

The site is static HTML first, and some tools need a server runtime.

## Decision

Host on Cloudflare Workers with static assets. The deploy pipeline is Mission 5.

## Consequences

Static pages and server tools share one hosting platform.

No trigger set.
