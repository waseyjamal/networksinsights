# 0002. Astro 7: static HTML first, JavaScript only in islands

Status: Accepted
Date: 2026-09-19

## Context

Every page must be complete HTML without JavaScript so crawlers can read it, and speed is a top goal.

## Decision

Use Astro 7. Pages are static HTML first. JavaScript ships only inside islands.

## Consequences

Pages stay fast and crawlable. Interactive UI must be written as islands.

## Revisit when

No trigger set.
